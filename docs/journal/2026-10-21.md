## Findings that change the plan
- One core saturates DRAM (~4.2 GB/s): extra cores help only with compute (dequantization).
- Stock kernel: `NO_HZ_FULL` off, `HUGETLBFS` off, `THP` off, 4 KB pages → phase 4 needs our
  own kernel build. `CPU_ISOLATION=y`, so `isolcpus` works on stock.
- CPU features `fp asimd evtstrm crc32 cpuid`: no `asimddp`, no `fphp/asimdhp`.
